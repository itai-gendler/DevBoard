# Protected task requests require accepted account credentials

When a selected scenario makes a protected HTTP request, the credential must verify as signed and unexpired, its Account must exist, and its token version must match the current account version. Issued credentials expire after thirty days. Missing, invalid, expired or version-mismatched credentials yield request rejection. This condition concerns request authentication; cached data and unauthenticated socket reception do not establish accepted credentials.
