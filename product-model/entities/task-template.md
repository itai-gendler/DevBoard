# Task template

A browser-local saved selection of task-form content.

## Information kept

- **Name** — The form title used as template name.
- **Title** — Saved task title.
- **Description** — Saved task description.
- **Priority** — Saved priority.
- **Tags** — Saved comma-separated tag input.
